# Publish Skill 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `PS-{nnn}`）
- [ ] `title` 清晰描述发布技能功能
- [ ] 触发条件明确
- [ ] 适用包/产品已列出

## 发布目标质量

- [ ] 发布目标注册中心已明确
- [ ] 认证方式已定义
- [ ] 多目标发布策略已定义（如适用）
- [ ] 发布目标与项目实际一致

## 前置验证

- [ ] 质量门禁检查项完整
- [ ] 合规门禁检查项已定义（如适用）
- [ ] 门禁检查顺序合理
- [ ] 门禁失败的处理方式已定义

## 发布流程质量

- [ ] 发布步骤可执行
- [ ] 每步有明确目的
- [ ] 命令可直接运行或有明确替换指引
- [ ] 发布后验证步骤完整

## 输入/输出契约

- [ ] 必需输入参数完整
- [ ] 参数类型和描述明确
- [ ] 输出格式定义完整（成功和失败）
- [ ] 错误码有标准分类

## 错误处理

- [ ] 常见错误有处理方案
- [ ] 认证失败有明确排查指引
- [ ] 网络错误有重试策略
- [ ] 版本冲突有处理方案

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策存在
- [ ] 关联发布策略存在
- [ ] 发布技能可追溯到治理需求

## 可测试性

- [ ] 发布流程可在沙箱/测试环境验证
- [ ] 示例输入/输出完整
- [ ] 回滚流程已定义
