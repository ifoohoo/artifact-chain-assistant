# Database Migration 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `MIG-{nnn}` 或时间戳）
- [ ] `title` 清晰描述迁移内容
- [ ] `database` 已指定
- [ ] 迁移类型已标注（DDL / DML / 混合）

## SQL 质量

- [ ] 正向迁移 SQL 语法正确
- [ ] 回滚 SQL 语法正确且与正向迁移对称
- [ ] SQL 已在测试环境验证
- [ ] 无硬编码环境变量或凭证

## 兼容性与安全

- [ ] 向前/向后兼容性已分析
- [ ] 应用停机需求已明确
- [ ] NOT NULL 约束处理策略已说明
- [ ] 默认值策略合理

## 回滚方案

- [ ] 回滚 SQL 完整可执行
- [ ] 回滚触发条件明确
- [ ] 回滚窗口已定义
- [ ] 回滚数据丢失风险已评估

## 性能影响

- [ ] 锁策略已评估
- [ ] 大表变更策略已说明（分批 / 在线 DDL）
- [ ] 预估执行时间合理
- [ ] 迁移期间监控方案已定义

## 验证方案

- [ ] 迁移前检查项完整
- [ ] 迁移后验证步骤可执行
- [ ] 数据完整性校验方案存在
- [ ] 回归测试覆盖关键场景

## 追溯性

- [ ] 关联数据契约存在
- [ ] 关联功能特性存在
- [ ] 迁移可追溯到 schema 变更原因
