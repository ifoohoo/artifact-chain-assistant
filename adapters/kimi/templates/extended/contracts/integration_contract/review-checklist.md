# Integration Contract 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `INT-{nnn}`）
- [ ] `title` 清晰描述集成范围
- [ ] `version` 字段存在且符合语义化版本
- [ ] `status` 字段存在且为有效值
- [ ] `protocol` 字段存在且为有效协议
- [ ] `external_system` 字段存在

## 连接配置

- [ ] 端点信息完整（开发 / 测试 / 生产）
- [ ] 认证方式已说明
- [ ] 凭证管理策略已定义
- [ ] 超时配置已定义（连接 / 读取 / 写入）

## 接口质量

- [ ] 所有接口有清晰描述
- [ ] 请求格式完整且示例正确
- [ ] 响应格式完整且示例正确
- [ ] 错误码覆盖常见异常场景
- [ ] 错误处理策略已说明

## 重试与熔断

- [ ] 重试规则已定义（最大次数、间隔、退避策略）
- [ ] 熔断配置已定义（阈值、时长、半开状态）
- [ ] 重试场景已分类
- [ ] 重试与熔断的边界已说明

## 错误处理

- [ ] 错误分类已定义（网络 / 认证 / 业务 / 系统）
- [ ] 每类错误的处理策略已说明
- [ ] 降级策略已定义
- [ ] 降级触发条件已明确
- [ ] 恢复策略已说明

## 幂等性

- [ ] 幂等键生成规则已定义
- [ ] 幂等存储方案已说明
- [ ] 幂等过期策略已定义
- [ ] 幂等性边界已说明

## 数据映射

- [ ] 字段映射表完整
- [ ] 类型转换规则已定义
- [ ] 数据格式转换逻辑已说明
- [ ] 枚举值映射已列出

## 监控与告警

- [ ] 关键监控指标已定义（成功率、响应时间、错误率）
- [ ] 告警规则已定义
- [ ] 告警级别和通知方式已说明
- [ ] 监控阈值合理

## 追溯性

- [ ] 关联功能特性存在
- [ ] 集成可追溯到业务需求
- [ ] 版本变更可追溯
- [ ] 关联设计文档存在

## 实现一致性

- [ ] 与实现代码一致
- [ ] 文档与实际行为匹配
- [ ] 测试覆盖核心场景
- [ ] 性能满足要求
