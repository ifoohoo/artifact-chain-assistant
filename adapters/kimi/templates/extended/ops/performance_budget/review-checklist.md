# Performance Budget 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `PERF-{nnn}`）
- [ ] `title` 清晰描述预算范围
- [ ] `scope` 已明确界定
- [ ] 基线版本已标注

## 指标定义质量

- [ ] 响应时间指标包含 P50/P95/P99
- [ ] 吞吐量目标合理且基于实际业务量
- [ ] 资源使用上限合理且基于硬件能力
- [ ] 错误率目标符合 SLA 要求

## 测量方法

- [ ] 测试工具和版本已指定
- [ ] 测试场景覆盖关键路径
- [ ] 并发数和数据量有代表性
- [ ] 测量流程可复现

## 回归检测

- [ ] 回归阈值明确
- [ ] CI 集成方案存在（如适用）
- [ ] 手动审查触发条件清晰
- [ ] 检测频率合理

## 基线管理

- [ ] 历史基线已记录
- [ ] 基线更新流程已定义
- [ ] 基线退化有告警机制

## 可操作性

- [ ] 超出预算时有排查指引
- [ ] 优化方向有建议
- [ ] 负责人已指定
- [ ] 审查周期已设定

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策存在
- [ ] 性能预算可追溯到业务需求
