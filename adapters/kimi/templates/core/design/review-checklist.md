# Design 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] 标题清晰表达设计范围
- [ ] 概述包含目标、范围和约束
- [ ] 至少包含架构视图和详细设计
- [ ] 关联制品字段完整

## 设计质量

- [ ] 设计目标具体可验证
- [ ] 组件职责单一明确
- [ ] 接口定义完整（输入/输出/错误）
- [ ] 数据流清晰可追溯

## 非功能需求

- [ ] 性能要求已识别
- [ ] 安全考虑已记录
- [ ] 可扩展性已设计

## 风险管理

- [ ] 风险已识别和评估
- [ ] 缓解措施具体可行
- [ ] 风险负责人已指定

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策已做出
- [ ] 设计可追溯到需求

## 可实现性

- [ ] 设计可在当前技术栈实现
- [ ] 工作量估算合理
- [ ] 依赖项已识别
