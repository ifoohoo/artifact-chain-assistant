# 阅读交付核对

- 本次选择与实际可交付范围清楚；制作和检查时重新核对专业成员，不从旧投影推断集合齐全。
- Graph 目标存在，原件与文章都符合制作阶段记录的摘要；构建没有回填绑定或刷新图锁。
- Docs 输入保留全文含义，标题、稳定章节和图节点可定位；原生图及依赖原样保留。
- 资源不依赖原目录或网络补齐，输出和原件不重叠；check 不修改文件，bundle 不覆盖已有目录。
- 预提交失败保留旧结果；已提交或不明失败保留两侧，按真实阶段报告，不声称万能回滚。
- 纯读者能取得完整包；维护者能在新目录按精确载荷继续制作、修订和重建。缺权限、未送达和未验证范围分别说明。
- 业务、表达、图文、结构、实现、验证和发布结论各自指向真实对象与范围，不由构建通过代签。
