# Data Contract 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `DATA-{nnn}`）
- [ ] `title` 清晰描述数据契约范围
- [ ] `version` 字段存在且符合语义化版本
- [ ] 数据格式已指定

## 数据模型质量

- [ ] Schema 定义完整
- [ ] 字段类型和约束明确
- [ ] 必填/可选标识正确
- [ ] 枚举值有文档说明

## 数据质量

- [ ] 数据质量规则已定义
- [ ] 验证方法可执行
- [ ] 监控指标已配置
- [ ] 告警阈值已设定

## 版本兼容性

- [ ] 兼容变更规则明确
- [ ] 破坏性变更已记录
- [ ] 迁移路径已规划
- [ ] 版本升级指南存在

## 追溯性

- [ ] 关联功能特性存在
- [ ] 数据生产者已识别
- [ ] 数据消费者已识别
- [ ] 数据血缘可追溯

## 实现一致性

- [ ] 与实际数据格式一致
- [ ] 文档与实现匹配
- [ ] 测试覆盖所有字段
- [ ] 数据验证已集成
