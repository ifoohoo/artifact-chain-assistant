# Hook Policy 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `HOOK-{nnn}`）
- [ ] `title` 清晰描述策略范围
- [ ] 适用范围已定义
- [ ] 执行阶段已指定

## 触发条件质量

- [ ] 触发事件明确
- [ ] 触发条件可验证
- [ ] 排除条件已定义
- [ ] 执行频率合理

## 门禁规则质量

- [ ] 规则描述清晰
- [ ] 检查内容具体
- [ ] 通过条件明确
- [ ] 失败处理有定义

## 绕过审批

- [ ] 绕过条件明确
- [ ] 审批流程完整
- [ ] 审批记录可追溯
- [ ] 绕过有效期已定义

## 执行脚本

- [ ] 脚本语法正确
- [ ] 错误处理完整
- [ ] 退出码语义明确
- [ ] 脚本可测试

## 审计与监控

- [ ] 审计日志格式完整
- [ ] 日志存储位置合理
- [ ] 监控指标已配置
- [ ] 告警阈值合理

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策存在
- [ ] 策略可追溯到安全需求

## 安全性

- [ ] 无硬编码凭证
- [ ] 权限最小化
- [ ] 敏感操作有审计
- [ ] 绕过有审批记录
