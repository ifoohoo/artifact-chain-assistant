# Prompt Packet 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `PP-{nnn}`）
- [ ] `title` 清晰描述 Prompt Packet 用途
- [ ] 适用场景已定义
- [ ] 目标 Agent/工具已指定

## 上下文组装质量

- [ ] 必需上下文来源已列出
- [ ] 上下文来源的类型和路径可解析
- [ ] 可选上下文有明确增强效果说明
- [ ] 无冗余或冲突的上下文来源

## Prompt 模板质量

- [ ] 系统提示覆盖角色和约束
- [ ] 用户提示结构清晰
- [ ] 占位符有明确来源和填充规则
- [ ] Prompt 模板无歧义指令

## 输出契约

- [ ] 期望输出格式已定义
- [ ] 质量标准可验证
- [ ] 输出格式与下游消费方匹配

## 组装流程

- [ ] 组装步骤清晰
- [ ] 每步有明确输入/输出
- [ ] 组装流程可自动化或半自动化执行

## 使用约束

- [ ] Token 预算已估算
- [ ] 更新频率合理
- [ ] 适用范围和排除情况已定义

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策存在
- [ ] Prompt Packet 可追溯到用户需求

## 可测试性

- [ ] 示例输入/输出完整
- [ ] 可在目标 Agent 环境中实际运行
- [ ] 输出质量可回归验证
