# Runbook 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `RUN-{nnn}`）
- [ ] `title` 清晰描述运维场景
- [ ] 适用场景已定义
- [ ] 负责人已指定

## 操作流程质量

- [ ] 步骤清晰可执行
- [ ] 命令准确无误
- [ ] 预期结果明确
- [ ] 验证方法可行

## 告警与监控

- [ ] 关键指标已识别
- [ ] 告警阈值合理
- [ ] 告警处理步骤明确
- [ ] 监控覆盖完整

## 回滚流程

- [ ] 回滚触发条件明确
- [ ] 回滚步骤可执行
- [ ] 回滚验证方法可行
- [ ] 回滚影响已评估

## 故障排查

- [ ] 常见问题已记录
- [ ] 排查步骤清晰
- [ ] 日志位置明确
- [ ] 联系人信息完整

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策存在
- [ ] 运维手册可追溯到系统设计

## 维护性

- [ ] 手册易于更新
- [ ] 步骤可验证
- [ ] 最近执行日期已记录
- [ ] 审核周期已设定
