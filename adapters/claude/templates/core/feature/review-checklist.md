# Feature 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `ACA{nn}`）
- [ ] `title` 字段存在且简洁明确
- [ ] `status` 字段存在且为有效值（draft/active/done/deprecated）
- [ ] 验收标准至少 3 条，每条可独立验证

## 内容质量

- [ ] 概述清晰描述问题域和解决目标
- [ ] 验收标准使用可测试的表述（避免"应该"、"可能"）
- [ ] 关联的场景 ID 存在且有效
- [ ] 设计约束已识别并记录

## 追溯性

- [ ] 至少关联一个场景或设计文档
- [ ] 关联的制品 ID 在图中可查
- [ ] 验收标准可追溯到场景测试

## 生命周期

- [ ] 草稿状态的 feature 可以缺少部分关联
- [ ] active 状态的 feature 必须有完整关联
- [ ] done/deprecated 状态的 feature 应记录完成原因
