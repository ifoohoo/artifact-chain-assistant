# 阅读与转交

从 index.html 打开这次选中的资料。左侧按标题和稳定身份定位，完整文章由 Docs 呈现；逻辑图保留原生入口。图中的对应关系由制作方声明，阅读、翻页和定位不表示你已经接受内容。

浏览器直接打开文件时，可能限制图节点点击。仍可使用步骤选择器打开对应正文，或独立打开文章和原生图。若机器已有 Python 3，可在这个阅读目录运行以下命令，再打开终端显示的本地地址；这条阅读路径不需要 npm。

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

本地地址只在这台机器可用。交给别人时须交付整个目录，不能只分享 localhost 地址。包内没有服务器端账户、评论、同步或接受记录服务。

没有找到相关资料时，保留原问题、本次已查范围及无法访问的部分，交给有项目资料访问权的维护者继续查找。文字匹配没有命中，不代表项目没有相关需求，也不代表查重已经完成。

“整理定位文本”只生成可以复制的文本。补上意见、提出者及必要背景，再通过双方已有的渠道交回；复制不表示已经保存、送达或受理。维护者实际收到后保存原话、对象、所见修订和位置，再按业务或表达意见处理。旧包保留当时的修订，不自动同步成最新版本。

生成目录不是文章手改的维护位置。要改业务或表达，请在项目说明指向的权威源中修改并核对，再制作新的阅读交付。没有证据或权限时保留未核实范围，不从文件存在、图能打开或构建通过推断实现、验证、发布或用户接受。
