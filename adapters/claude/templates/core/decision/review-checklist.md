# Decision 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `D-{PREFIX}-{nn}`）
- [ ] `title` 字段存在且清晰表达决策主题
- [ ] `status` 字段存在且为有效值（proposed/accepted/deprecated/superseded）
- [ ] `date` 字段记录决策日期

## 决策质量

- [ ] 背景清晰描述问题域
- [ ] 至少考虑 2 个选项
- [ ] 每个选项有优缺点分析
- [ ] 决策理由与驱动因素一致

## 追溯性

- [ ] 关联相关功能特性或设计文档
- [ ] 决策影响范围已识别
- [ ] 相关方已通知或参与

## 可验证性

- [ ] 影响分析包含正面和负面
- [ ] 验证方法可执行
- [ ] 决策可追溯到实际实现

## 生命周期

- [ ] proposed 状态应有决策期限
- [ ] accepted 状态应有实现计划
- [ ] deprecated/superseded 应记录替代决策 ID
