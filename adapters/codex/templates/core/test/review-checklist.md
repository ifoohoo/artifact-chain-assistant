# Test 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 测试结构

- [ ] 测试文件组织清晰（按模块或功能）
- [ ] 测试命名描述预期行为
- [ ] 使用 Arrange-Act-Assert 或 Given-When-Then 模式
- [ ] 测试独立，不依赖执行顺序

## 覆盖质量

- [ ] 正常路径已覆盖
- [ ] 边界条件已测试
- [ ] 异常路径已覆盖
- [ ] 关键业务逻辑测试充分

## 代码质量

- [ ] 测试代码可读性好
- [ ] 避免测试实现细节
- [ ] Mock 使用合理，不过度 mock
- [ ] 断言明确具体

## 追溯性

- [ ] 测试关联功能特性（通过追溯注释）
- [ ] 测试覆盖验收标准
- [ ] 测试可追溯到需求

## 可维护性

- [ ] 测试易于理解和修改
- [ ] 测试数据构造清晰
- [ ] 测试环境隔离
- [ ] 测试执行稳定（无随机失败）
