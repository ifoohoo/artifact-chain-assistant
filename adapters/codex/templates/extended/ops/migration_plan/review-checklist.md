# Migration Plan 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `MPLAN-{nnn}`）
- [ ] `title` 清晰描述迁移范围
- [ ] `scope` 已明确界定
- [ ] 迁移策略已选择

## 阶段划分

- [ ] 阶段划分合理且相互独立
- [ ] 每阶段有明确目标和交付物
- [ ] 时间窗口现实可行
- [ ] 验证标准可度量

## 回滚方案

- [ ] 每个阶段有明确回滚点
- [ ] 回滚触发条件清晰
- [ ] 回滚操作具体可执行
- [ ] 回滚窗口已定义且合理

## 数据迁移

- [ ] 数据量已评估
- [ ] 迁移方式已选择
- [ ] 一致性保证策略已说明
- [ ] 数据验证方案存在

## 并行运行

- [ ] 并行运行范围已定义
- [ ] 数据同步方式已说明
- [ ] 切换标准明确
- [ ] 并行运行时长合理

## 风险评估

- [ ] 关键风险已识别
- [ ] 概率和影响已评估
- [ ] 缓解措施具体可行
- [ ] 风险升级机制存在

## 依赖管理

- [ ] 关键依赖已识别
- [ ] 依赖状态已跟踪
- [ ] 依赖风险已评估

## 沟通与验收

- [ ] 沟通计划已制定
- [ ] 验收标准明确可度量
- [ ] 利益相关方已识别

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策存在
- [ ] 迁移计划可追溯到业务驱动因素
