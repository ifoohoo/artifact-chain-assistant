# Agent Skill 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `SKILL-{nnn}`）
- [ ] `title` 清晰描述技能功能
- [ ] 触发条件明确
- [ ] 适用场景已定义

## 输入/输出质量

- [ ] 必需输入参数完整
- [ ] 参数类型和描述明确
- [ ] 输出格式定义完整
- [ ] 错误输出有标准格式

## 处理流程

- [ ] 处理步骤清晰
- [ ] 每个步骤有明确输入/输出
- [ ] 错误处理路径已定义
- [ ] 边界条件已考虑

## 工具依赖

- [ ] 工具依赖已列出
- [ ] 权限要求明确
- [ ] 工具调用有错误处理
- [ ] 无循环依赖

## 权限安全

- [ ] 可访问资源已定义
- [ ] 禁止操作已列出
- [ ] 数据访问范围合理
- [ ] 敏感操作有审批

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策存在
- [ ] 技能可追溯到用户需求

## 可测试性

- [ ] 示例输入/输出完整
- [ ] 测试用例覆盖正常路径

- [ ] 边界条件已测试
