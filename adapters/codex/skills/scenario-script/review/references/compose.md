# scenario-script compose

内部工序，不作为 catalog 入口。

## 目的

基于 inspect 结果编写场景剧本制品的 frontmatter 和正文。

## 步骤

### 1. 确定制品 ID

- 从项目 `idPatterns` 中场景类型对应的 pattern 派生合法 ID
- 检查与已有制品 ID 不冲突
- ID 应简短且具有业务语义

### 2. 编写 frontmatter

从 inspect 输出的项目模板、配置和同类制品派生 frontmatter。不得自行增加项目未采用的字段或状态。

### 3. 编写正文结构

正文应覆盖角色与目标、前置条件、主路径、异常路径、可观察结果和必要追溯等通用质量维度；具体章节名和布局从项目模板与已有制品派生。

### 4. 场景步骤编写规则

每个主路径和异常路径步骤必须：
- 使用编号列表
- 以动词开头
- 包含可验证的条件（不使用"足够""合理""尽快"等模糊词）
- 每个异常路径描述触发条件和预期处理方式

### 5. 文件放置

- 文件名按项目制品命名模式（从已有制品扫描结果派生）
- 路径按项目中场景剧本注册类型的 paths 配置
- 文件名与 ID 保持可追溯对应

## 输出

compose 输出供 validate 和 review 消费：
- 完整的制品文件内容
- 制品 ID 和路径
