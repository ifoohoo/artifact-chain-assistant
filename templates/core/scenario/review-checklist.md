# Scenario 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `S-{nn}`）
- [ ] `title` 字段存在且描述场景本质
- [ ] `status` 字段存在且为有效值
- [ ] 角色与目标清晰定义

## 流程质量

- [ ] 主流程使用 Given/When/Then 格式
- [ ] 至少覆盖一个备选流程
- [ ] 前置条件可验证
- [ ] 系统响应具体可测试

## 追溯性

- [ ] 关联至少一个功能特性
- [ ] 关联的功能特性 ID 存在
- [ ] 场景可追溯到功能需求

## 可执行性

- [ ] 场景可以手动或自动执行
- [ ] 验收标准与流程步骤一致
- [ ] 备选流程覆盖关键异常路径
