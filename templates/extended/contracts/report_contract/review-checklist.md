# Report Contract 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `RPT-{nnn}`）
- [ ] `title` 清晰描述报告范围
- [ ] `version` 字段存在且符合语义化版本
- [ ] `status` 字段存在且为有效值
- [ ] `output_format` 字段存在且为有效格式

## 数据源质量

- [ ] 所有数据源已列出
- [ ] 数据源类型明确（数据库 / API / 文件）
- [ ] 数据刷新频率已定义
- [ ] 数据源可靠性已评估

## 字段定义

- [ ] 所有字段有清晰的中文/英文名称
- [ ] 字段类型明确（string / number / date / boolean）
- [ ] 聚合逻辑已定义（SUM / AVG / COUNT / MAX / MIN / NONE）
- [ ] 字段含义有详细说明

## 时间窗口

- [ ] 报告周期已定义
- [ ] 时间粒度已明确（小时 / 天 / 周 / 月）
- [ ] 时区已指定
- [ ] 截止规则已说明

## 聚合逻辑

- [ ] 关键指标计算规则完整
- [ ] 过滤条件已列出
- [ ] 排序规则已定义
- [ ] 边界情况处理已说明（如空值、零值）

## 性能与安全

- [ ] 生成时间要求已定义
- [ ] 数据量级已评估
- [ ] 并发支持已说明
- [ ] 数据权限已定义
- [ ] 敏感字段已标记并说明脱敏方式

## 追溯性

- [ ] 关联功能特性存在
- [ ] 报告可追溯到业务需求
- [ ] 版本变更可追溯
- [ ] 关联数据契约存在

## 实现一致性

- [ ] 报告输出与定义一致
- [ ] 字段计算逻辑与实现匹配
- [ ] 性能满足要求
- [ ] 测试覆盖核心场景
