# API Contract 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `API-{nnn}` 或 `{service}-API-{version}`）
- [ ] `title` 清晰描述 API 范围
- [ ] `version` 字段存在且符合语义化版本
- [ ] `status` 字段存在且为有效值

## 接口质量

- [ ] 每个端点有清晰描述
- [ ] 请求参数类型和必填性明确
- [ ] 响应格式完整且示例正确
- [ ] 错误码覆盖常见异常场景

## 数据模型

- [ ] 数据模型定义完整
- [ ] 字段类型和约束明确
- [ ] 枚举值有文档说明
- [ ] 嵌套关系清晰

## 安全性

- [ ] 认证方式已说明
- [ ] 敏感字段已标记
- [ ] 权限要求已记录
- [ ] 速率限制已说明（如适用）

## 追溯性

- [ ] 关联功能特性存在
- [ ] API 可追溯到业务需求
- [ ] 版本变更可追溯

## 实现一致性

- [ ] 与实现代码一致
- [ ] 文档与实际行为匹配
- [ ] 测试覆盖所有端点
