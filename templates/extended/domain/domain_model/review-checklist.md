# Domain Model 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `DM-{nnn}` 或实体名）
- [ ] `title` 清晰描述领域模型
- [ ] 领域上下文已定义
- [ ] 通用语言已建立

## 领域设计质量

- [ ] 聚合边界清晰
- [ ] 聚合根职责单一
- [ ] 实体和值对象区分正确
- [ ] 不变量已定义且可验证

## 事件设计

- [ ] 领域事件已识别
- [ ] 事件触发条件明确
- [ ] 事件消费者已识别
- [ ] 事件命名符合通用语言

## 服务设计

- [ ] 领域服务职责明确
- [ ] 服务接口定义完整
- [ ] 仓储接口抽象合理
- [ ] 无循环依赖

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策存在
- [ ] 领域模型可追溯到业务需求

## 实现一致性

- [ ] 与实现代码一致
- [ ] 领域模型可落地为代码
- [ ] 测试覆盖核心逻辑
