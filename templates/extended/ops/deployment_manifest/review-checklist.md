# Deployment Manifest 审查清单

<!-- 本清单是插件通用基线，项目本地审查规则可覆盖 -->

## 结构完整性

- [ ] `id` 字段存在且符合项目 ID 模式（如 `DEP-{nnn}` 或环境名）
- [ ] `title` 清晰描述部署范围
- [ ] `environment` 已指定
- [ ] 部署信息完整

## 部署流程质量

- [ ] 前置条件明确
- [ ] 部署步骤可执行
- [ ] 验证方法可行
- [ ] 回滚计划完整

## 资源配置

- [ ] 资源规格合理
- [ ] 环境变量完整
- [ ] 配置与环境匹配
- [ ] 敏感信息已加密

## 健康检查

- [ ] 存活检查已配置
- [ ] 就绪检查已配置
- [ ] 超时设置合理
- [ ] 检查端点可访问

## 回滚计划

- [ ] 回滚触发条件明确
- [ ] 回滚步骤可执行
- [ ] 回滚验证方法可行
- [ ] 回滚影响已评估

## 监控与告警

- [ ] 关键指标已识别
- [ ] 告警阈值合理
- [ ] 告警通知配置正确
- [ ] 监控覆盖完整

## 追溯性

- [ ] 关联功能特性存在
- [ ] 关联决策存在
- [ ] 部署清单可追溯到版本
